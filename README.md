## 5. Scenario-Based Demo & Practice Questions

### Question 1
Which OCI service leverages machine learning to cluster millions of heterogeneous application and operating system log lines into small clusters of related issues, identifying root causes rapidly?

A) OCI Logging Analytics
B) Object Storage Lifecycle Engine
C) FastConnect BGP Monitor
D) Service Gateway Route Table

- **Correct Answer**: `A) OCI Logging Analytics`  
- **Technical Explanation**: OCI Logging Analytics provides advanced AI and machine learning log processing, including clustering, link analysis, and anomaly detection across massive volumes of log data.

### Question 2
How does OCI Application Performance Monitoring (APM) capture and visualize end-to-end user transactions across microservices, databases, and third-party APIs?

A) Through distributed tracing using open-source OpenTelemetry standards and APM tracers
B) By pinging the web server every hour
C) Through physical serial cable connections
D) By checking firewall rule configurations

- **Correct Answer**: `A) Through distributed tracing using open-source OpenTelemetry standards and APM tracers`  
- **Technical Explanation**: OCI APM supports OpenTelemetry standards to collect distributed traces across frontend clients, microservices, and database calls, tracking latency bottlenecks across the stack.
